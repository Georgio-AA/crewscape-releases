# Crewscape releases

Installers and update files for **Crewscape**, a Windows desktop app that shows the Claude
and Codex work on your computer as a live office.

**Download:** `Crewscape-Setup-<version>-x64.exe` from the
[latest release](https://github.com/Georgio-AA/crewscape-releases/releases/latest).
Once installed, Crewscape updates itself from the releases published here.

This repository only holds release files; the source code is kept elsewhere.
